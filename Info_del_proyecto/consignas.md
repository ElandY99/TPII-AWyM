# Consignas TP3

1. CONSIGNAS
Continuando con el proyecto integrador de la asignatura, cada grupo deberá
desarrollar el Back-End del Sistema de Gestión de Turnos Médicos, implementando la
lógica de negocio, la persistencia de datos y la comunicación con el Front-End
desarrollado en el Trabajo Práctico N.º 2.
La aplicación deberá permitir administrar la información mediante operaciones CRUD,
gestionar la autenticación y autorización de usuarios e implementar Servicios REST
para la comunicación entre el cliente y el servidor.
Como mínimo, el sistema deberá contemplar los siguientes módulos:
▪ Autenticación de usuarios.
▪ Gestión de pacientes.
▪ Gestión de médicos.
▪ Gestión de especialidades.
▪ Gestión de turnos médicos.
▪ Administración de usuarios (según roles).
▪ Servicios REST para la comunicación con el Front-End.
2. ASPECTOS A CONSIDERAR
Durante el desarrollo del proyecto deberán contemplarse, como mínimo, los siguientes
aspectos:
Arquitectura y organización
▪ Organización modular del proyecto Back-End.
▪ Separación entre presentación, lógica de negocio y acceso a datos.
▪ Organización adecuada del código fuente.
Base de datos
▪ Implementación del modelo de datos definido en el Trabajo Práctico N.º 1.
▪ Creación de la base de datos y sus relaciones.
▪ Integridad referencial mediante claves primarias y foráneas.
Operaciones CRUD
Implementar las siguientes operaciones para las principales entidades del sistema.
▪ Alta de registros.
▪ Consulta de información.
▪ Modificación de datos.
▪ Eliminación de registros.
Seguridad
Implementar mecanismos de:
▪ Autenticación de usuarios.
▪ Gestión de sesiones.
▪ Autorización basada en roles.
▪ Protección de credenciales.
▪ Consultas parametrizadas.
▪ Validación de datos del servidor.
Servicios REST
Implementar Servicios REST para la comunicación con el Front-End utilizando los
principales métodos HTTP: GET, POST, PUT, DELETE
Las respuestas deberán intercambiar información en formato JSON.
Integración
Integrar completamente el Front-End desarrollado en el Trabajo Práctico N.º 2 con el
Back-End implementado en esta unidad.
